# Специфікація adr-lint

## 1. Вхід

Один аргумент - шлях до файлу журналу рішень у форматі Markdown.

## 2. Розбір

Кожен ADR починається з рядка виду:

    ## ADR-0007 - Короткий заголовок

Одразу під заголовком ідуть метадані:

    Status: accepted
    Date: 2026-04-11

Далі йдуть секції третього рівня.

## 3. Обовʼязкові секції

У кожного ADR мають бути рівно чотири секції третього рівня, у цьому порядку:

    ### Context
    ### Decision
    ### Alternatives
    ### Consequences

## 4. Дозволені статуси

    proposed
    accepted
    superseded

## 5. Перевірки

| Код | Перевірка |
|-----|-----------|
| E1  | Номер ADR не повторюється |
| E2  | Усі чотири обовʼязкові секції присутні |
| E3  | Статус входить у перелік дозволених |
| E4  | Кожне посилання виду ADR-NNNN веде на ADR, який існує у файлі |

## 6. Вихід

Спочатку індекс: номер, заголовок, статус, дата.
Далі перелік знайдених проблем: код, номер ADR, один рядок пояснення.
Код повернення 0, якщо проблем немає, інакше 1.
