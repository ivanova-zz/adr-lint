# adr-lint

Маленький валідатор журналу архітектурних рішень.

Проєкт веде один файл `DECISIONS.md`. Кожен запис у ньому - це ADR
(Architecture Decision Record): пронумероване рішення з обґрунтуванням.

## Статуси

Запис може мати один зі статусів:

- `draft` - чернетка, ще обговорюється
- `accepted` - прийнято, діє
- `rejected` - відхилено

## Формат запису

Заголовок другого рівня, далі рядок `Status:`, рядок `Date:`, далі секції
третього рівня.

## Запуск

    adr-lint DECISIONS.md
