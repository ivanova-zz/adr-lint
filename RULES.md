# Rules for the coding agent

- Work only inside this repository.
- Do not modify spec.md, README.md or DECISIONS.md.
- You may create or modify implementation files, tests and the four task-report files.
- Do not access the network or install runtime dependencies unless explicitly requested.
- Do not add features not required by spec.md.
- Prefer Python standard library for implementation.
- Tests may use pytest.
- If the specification is ambiguous, do not silently guess. Record the chosen interpretation in DECISION.md before implementing it.
- Run tests and the CLI against DECISIONS.md before declaring the task complete.
- Keep commits small and focused.
